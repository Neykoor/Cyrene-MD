## ✦ Sobre el proyecto

Cyrene-MD es un proyecto público de un bot de WhatsApp enfocado en ofrecer una estructura sencilla y fácil de editar.

La idea es explorar el rendimiento y las posibilidades de combinar:

- TypeScript
- CommonJS
- Baileys
- Sistema de botones
- Una estructura sencilla y fácil de modificar

El objetivo es que puedas editar diferentes partes del bot sin tener que perderte entre demasiadas carpetas y rutas.

## ⚡ ¿Qué buscamos?

> «Explorar el rendimiento de CommonJS + TypeScript en un bot de WhatsApp.»

Cyrene-MD nace como un proyecto experimental y público para probar qué tan bien puede funcionar esta combinación en un bot moderno basado en Baileys.

## 📦 Baileys

Cyrene-MD utiliza **BaileysXS**, un fork basado en:

- [Ryzewa](https://github.com/Davizuni17/Ryzewa)
- [BaileysXS](https://github.com/Neykoor/BaileysXS)

BaileysXS es el fork utilizado actualmente por este proyecto.

## 📱 ¿Termux?

**¿Funcionará en Termux?**

> «No se veremos.»

El proyecto puede ser probado en diferentes entornos, pero la compatibilidad y rendimiento en Termux quedan como parte de la experimentación del proyecto.
